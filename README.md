# Neon Runner 3D

A small browser-based 3D endless runner built with Three.js.

## Play

After GitHub Pages finishes deploying:

`https://ttttest123455.github.io/3d-web-game/`

## Controls

- **A / D** or **← / →** — change lanes
- **Space** — temporary dash
- Touch buttons are available on mobile

## Stack

- HTML / CSS / JavaScript
- Three.js loaded from jsDelivr
- GitHub Actions + GitHub Pages

No build step is required.
